================================================================================
AGENT CONVERSATION FLOW — MFH (Mehrfamilienhaus)
================================================================================

This is the ideal conversation flow for the expose agent to collect all data
needed to produce a bundle PDF + individual apartment PDFs matching the manual
flow output. The agent should follow this exact sequence.

Seller can provide data in bulk or one question at a time — the agent adapts.
But it must NOT skip to pricing/draft until ALL phases are complete.

────────────────────────────────────────────────────────────────────────────────
PHASE 9 — ENTWURF + QUALITÄTSPRÜFUNG (automatic)
────────────────────────────────────────────────────────────────────────────────

     → Agent: listing_draft (automatic)
       Generates: titleShort, descriptionLong, locationDescription,
       buildingDescription, highlights, exposeHeadline, exposeSubheadline

     → Agent: listing_review (automatic)
       Checks: GEG fields, word count, hallucination, superlatives, photos, price
       If fails on fixable issues → auto-revise up to 2x (self-healing)
       If fails on data issues → asks seller

     → Agent shows draft to seller:
       "Ihr Exposé-Entwurf ist fertig und hat die Qualitätsprüfung bestanden.
        Überschrift: ...
        Kurztitel: ...
        Beschreibung: ...
        Möchten Sie das Inserat erstellen?"

Q31: "Möchten Sie das Inserat erstellen?"
A:   Ja

     → Agent: handoff_commit
     → Creates: Property + Units + Listings + PriceRecommendations + MediaAssets
     → Generates: Bundle PDF + individual apartment PDFs (via on-demand route)
